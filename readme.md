# 图片压缩工具

一个具有现代化Win11风格UI的图片压缩工具，可以在保持图片质量的同时有效减小文件大小。

## 功能特点

- 现代化Win11风格用户界面
- 支持批量处理多个图片
- 可调节压缩质量
- 智能处理各种图片格式
- 自动保留PNG透明通道
- 实时显示压缩进度和结果
- 详细的压缩日志
- 自定义输出目录功能
- 记忆上次设置的输出目录和压缩质量

## 安装

1. 确保已安装Python 3.7+
2. 安装所需依赖：

```bash
pip install -r requirements.txt
```

## 使用方法

1. 运行程序：

```bash
python image_compress.py
```

2. 点击"选择图片文件"按钮选择需要压缩的图片（支持多选）
3. 点击"选择输出目录"按钮设置图片输出位置（默认为当前目录下的output文件夹）
4. 调整压缩质量滑块（默认90%）
5. 点击"开始压缩"按钮开始批量处理
6. 压缩完成后，可以在设置的输出目录中找到压缩后的图片

## 程序记忆功能

程序会记住您上次设置的：
- 输出目录位置
- 压缩质量设置

下次启动程序时将自动使用这些设置，无需重新配置。

## 支持的图片格式

- JPEG/JPG
- PNG (保留透明通道)
- BMP
- GIF
- TIFF

## 技术说明

- 使用PIL/Pillow库进行图像处理
- 使用CustomTkinter创建现代化UI
- 多线程处理，保持UI响应性
- 智能处理不同图片格式的特性
- 使用JSON文件保存用户配置
